### 1.5 总指挥 LLM

用户确认：**复用 Claude（已有授权）**，同时保留 `LlmProvider` 抽象以便后续切换。

**当前阻塞**：Windows 侧 Claude 授权存于系统凭据管理器 / `.claude.json`，WSL 内 `~/.claude/` 与 `~/.claude.json` 均不存在，无法直接复用。需要用户在 WSL 终端手动执行一次授权：

```bash
export PATH="$HOME/.npm-global/bin:$PATH"
claude   # 首次运行触发浏览器登录，使用与 Windows 相同的 Claude 账号
```

授权完成后 `~/.claude/` 与 `~/.claude.json` 会生成，Hub 即可通过 `LlmProvider` 调用。

## 二、与原设计的差异（以本文为准）

| 项 | 原设计 | 实际 | 原因 |
| --- | --- | --- | --- |
| MySQL 部署 | apt 原生 systemd | Docker 容器 | 用户明确指定 Docker Desktop |
| Redis 部署 | apt 原生 systemd | Docker 容器 | 同上 |
| MySQL 端口 | 3306 | **13306** | 避免与其他实例冲突 |
| Redis 端口 | 6379 | **16379** | Windows 宿主 6379 已被占用 |
| Agent 发现 | `which` / PATH | **绝对路径** | PATH 里 Windows shim 优先且不可用 |
| 总指挥 LLM | 未定 | Claude（待 WSL 授权） | 用户确认 |
